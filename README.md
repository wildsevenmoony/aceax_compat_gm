# ACE3 Arsenal Extended - Global Mobilisation

ACE3 Arsenal Extended compatibility for the Arma 3 Creator DLC Global Mobilisation - Cold War Germany.

This mod adds ACE Arsenal Extended model, type, camo, and variant groupings for Global Mobilisation equipment so related gear appears as compact ACEAX selections instead of long lists of individual classnames.

This compat was shamelessly created with the help of AI, then manually reviewed, edited, and tested.

## Features

- ACEAX groupings for Global Mobilisation weapons and equipment.
- Self-contained family names for Global Mobilisation gear.
- Coverage for manually declared Arsenal-relevant items.
- No gameplay balance changes and no new assets.

## Requirements

- Arma 3
- CBA
- ACE3
- ACE3 Arsenal Extended
- Global Mobilisation - Cold War Germany Creator DLC

## Building

This repository is structured as a HEMTT-based Arma 3 mod project.

Common commands:

```sh
hemtt check
hemtt build
hemtt release
```

Generated build output, releases, private keys, packed PBO files, and signatures are ignored by Git.
